# Выбор событий для External Webhooks

Теперь [вебхук](https://faq-ru.kaiten.site/external-webhooks) можно настроить так, чтобы он передавал во внешний сервис только нужные события. Например, оповещал, только когда карточку завершили, а не при каждом изменении в ней.

📸 *Скриншот: поле «Фильтр событий» при настройке вебхука*

*Функция уже доступна облачным клиентам Kaiten. В серверной поставке начиная с версии 58.81.0*

---

Раньше вебхук срабатывал на любое событие в пространстве: на создание и перемещение карточек, на новые комментарии или добавленный файл. Внешнее приложение получало все уведомления. Теперь вы сами выбираете, какие события передавать. Например, можно настроить интеграцию так, чтобы бот писал в чат только после завершения карточки.

Настроить события можно там же, где вы управляете вебхуками:

* в настройках пространства → раздел External Webhooks;
* в административном разделе External Webhooks.

---

## Как выбрать события для External Webhooks в настройках пространства

> Доступ к разделу External Webhooks в настройках пространства по умолчанию есть у владельца аккаунта и пользователей с ролью администратора. Выдать доступ пользователям с другими ролями можно через [настраиваемые роли](https://faq-ru.kaiten.site/nastraivaemye-roli-polzovateley).

1. В левой панели откройте настройки пространства и перейдите в раздел External Webhooks.

2. Создайте новый вебхук или откройте уже созданный. В разделе «Фильтр событий» в строке «События» по умолчанию будет установлено «Все события». Нажмите на нее, чтобы выбрать нужные.

![Картинка](Скриншот: выбор событий в поле «Фильтр событий»)

События в интерфейсе соответствуют событиям из [документации](https://developers.kaiten.ru/external-webhooks).

## Как выбрать события в административном разделе External Webhooks

> По умолчанию раздел External Webhooks доступен владельцу аккаунта и пользователям с доступом к разделу «[Пользователи](https://faq-ru.kaiten.site/polzovateli-administrativnyy-razdel)». Если вы хотите получить доступ к External Webhooks в администрировании, обратитесь к одному из них.

1. Откройте административный раздел External Webhooks. Перед вами откроется таблица со всеми вебхуками аккаунта. В ней появилась колонка «События», в которой видно, на какое событие настроен каждый вебхук.

![Картинка](Скриншот: таблица External Webhooks с колонкой «События»)

2. Создайте новый вебхук или откройте уже созданный. Для этого нажмите на нужную строку в таблице.

3. В поле «Фильтр по событиям» выберите события, о которых вебхук должен сообщать. По умолчанию выбраны все.

4. Сохраните.
