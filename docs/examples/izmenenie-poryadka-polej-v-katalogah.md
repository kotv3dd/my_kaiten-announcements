# Изменение порядка полей в каталогах

Теперь порядок полей в [каталогах](https://faq-ru.kaiten.site/katalogi) можно менять. Переносите наверх поля, которые используете чаще всего, чтобы не искать их в длинных формах.

📸 *Скриншот 1: блок «Поля каталога», слева у полей появились точки для перетаскивания*

Функция уже доступна облачным клиентам Kaiten. В серверной поставке начиная с версии 58.55.7.

> ⚠️ Порядок полей меняют в разделе «Каталоги» административной панели. Доступ к нему есть у пользователей с правом создавать пользовательские поля; его выдает владелец аккаунта или администратор.

---

## Что изменилось

Раньше поля располагались в том порядке, в котором были созданы. Изменить его было нельзя. Если нужно было поставить важные поля выше, приходилось удалять их и создавать заново, из-за чего терялись уже заполненные данные. Теперь поля можно менять местами.

## Как поменять порядок полей

1. Откройте раздел «Каталоги» в административной панели.
2. Нажмите на карандаш у нужного каталога.

📸 *Скриншот 2: список каталогов, вход в редактирование по карандашу*

3. В блоке «Поля каталога» захватите поле за точки слева и перетащите на нужное место.
4. Сохраните каталог.

Заполненные данные останутся на месте: пересоздавать поля не нужно.
