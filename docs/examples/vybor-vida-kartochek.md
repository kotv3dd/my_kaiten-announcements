# Выбор вида карточек для каждого пространства

Теперь для каждого [пространства](https://faq-ru.kaiten.site/chto-takoe-prostranstvo) можно выбрать свой вид карточек: в одном использовать компактный, а в другом — полный или настроить собственный. Панель настройки тоже обновили. Вместо отдельного окна теперь открывается боковая панель, где можно выбирать, создавать и редактировать виды карточек.

![Картинка 1](https://hq.kaiten.ru/api/documents/43962c19-488a-4252-9a57-e101ce04f657/files/352964cf-4c60-44a0-abd7-5d8394e33375)

*Функция уже доступна облачным клиентам Kaiten. В серверной поставке начиная с версии 58.51.0.*

---

Раньше, когда вы выбирали вид карточек, он применялся ко всем пространствам. Это было неудобно, потому что где-то в карточке нужно видеть, например, [метки или теги](https://faq-ru.kaiten.site/metki-tegi-leybly), а где-то нет.

Теперь на каждом пространстве можно настроить свой вид карточек: для проектного выбрать полный, для командного — компактный, а для CRM настроить свой.

## Что изменилось

### Боковая панель вместо диалогового окна

Раньше виды карточек открывались во всплывающем окне. Теперь вместо него используется боковая панель. 

* Слева находится список видов карточек. Активный вид выделен цветом, а рядом указано, применяется он только к текущему пространству или ко всем.

* Справа находится окно предпросмотра, где можно посмотреть, как будет выглядеть карточка на пространстве.

![Картинка 2](https://hq.kaiten.ru/api/documents/43962c19-488a-4252-9a57-e101ce04f657/files/0320fbb0-a46c-4114-8814-d856557f6ae4)

**Боковая панель с видами карточек. Активный вид выделен.**

В панели появились вкладки с категориями «Все», «Мои», «Командные» и «Системные». С ними проще найти нужный вид карточек, если их стало много.

![Картинка 3](https://hq.kaiten.ru/api/documents/43962c19-488a-4252-9a57-e101ce04f657/files/0a6d8d43-8280-4b70-91bc-1fa17674c819)

**Категории видов карточек**

Чтобы создать новый вид карточек, нажмите кнопку «Создать вид» в правом нижнем углу или в категории «Мои», если там еще пусто. 

![Картинка 4](https://hq.kaiten.ru/api/documents/43962c19-488a-4252-9a57-e101ce04f657/files/f1dc8632-c60f-44fd-8194-68a200823769)

## Как применить вид

1. Нажмите на вид карточки, чтобы выбрать его.

2. Внизу панели укажите, к чему его применить: к текущему пространству или ко всем сразу.

3. Нажмите кнопку «Применить». 

![Картинка 5](https://hq.kaiten.ru/api/documents/43962c19-488a-4252-9a57-e101ce04f657/files/04e0c930-2f7b-4d77-840e-4162e5569067)

**Выбор вида с применением только к текущему пространству**

Если выбрать «Ко всем пространствам», перед применением вида Kaiten покажет окно подтверждения, чтобы это не произошло неожиданно.

![Картинка 6](https://hq.kaiten.ru/api/documents/43962c19-488a-4252-9a57-e101ce04f657/files/baa6a4a5-6d7f-47ea-8409-f9aab297e61d)
