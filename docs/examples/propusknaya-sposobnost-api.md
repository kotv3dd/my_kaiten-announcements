# Кратно подняли пропускную способность нашего API для интеграций

Лимит запросов вырос в **10 раз**: теперь через [API Kaiten](https://developers.kaiten.ru) можно выполнять до **50 запросов в секунду на компанию** вместо прежних 5. Изменение особенно заметно при активной работе с API: чем больше запросов отправляет ваша система, тем стабильнее и быстрее будет обмен данными с Kaiten.

![Картинка 1](https://hq.kaiten.ru/api/documents/804acedb-078b-41d5-a376-9b8b9713794f/files/bff3d846-27cb-4cc1-b614-2c82d56eb631)

С новым лимитом вы можете:

* синхронизировать задачи с CRM, ERP или Helpdesk в обе стороны без задержек;

* обрабатывать поток входящих заявок через ботов и скрипты в режиме реального времени;

* подключать ИИ-инструменты, которые обращаются к Kaiten для чтения и обновления данных;

* строить внутренние дашборды и отчёты, которые тянут актуальные данные без ограничений.

Подробнее: [developers.kaiten.ru](https://developers.kaiten.ru/)
