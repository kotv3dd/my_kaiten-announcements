# Новый интерфейс редактора комментариев в карточках

В [карточках](https://faq-ru.kaiten.site/chto-takoe-kartochka) редактор комментариев стал таким же, как редактор описания. Теперь для форматирования текста используется единый интерфейс: нужные инструменты находятся в одном месте, а лишние элементы убраны из нижней панели.

![Картинка 1](https://hq.kaiten.ru/api/documents/d6080573-8a6c-40cd-9c23-9a6a58a296fa/files/9606cef6-ca84-40a2-9c97-395079ab0d2f)

*Функция уже доступна облачным клиентам Kaiten. Для on-premise — после обновления до последней версии*.

---

Раньше редакторы описания и комментариев в карточке выглядели по-разному. В описании использовалась одна панель инструментов, а в комментариях — другая. Из-за этого одинаковые действия находились в разных местах, а некоторые функции дублировались. 

**Что изменилось**:

1. На верхней панели редактора располагаются основные действия: прикрепление файлов, добавление ссылок, упоминание пользователей и GIF.

2. Инструменты форматирования текста (заголовки, списки, цитаты, таблицы, код, изображения и другие элементы) теперь доступны через меню форматирования на верхней панели — так же, как в описании карточки.

3. Переключение между визуальным режимом и Markdown стало одинаковым в обоих редакторах и находится в правой части панели инструментов.

4. Из нижней панели комментария убраны дублирующиеся действия: прикрепление файлов, ссылки, упоминания, GIF, эмодзи, внешние адресаты и пункт «Редактировать как Markdown».

![Картинка 2](https://hq.kaiten.ru/api/documents/d6080573-8a6c-40cd-9c23-9a6a58a296fa/files/0da36cf2-4e56-40b8-8ac0-38bff6f654ad)

*Сверху — прежний редактор комментариев. Снизу — обновленный.*
