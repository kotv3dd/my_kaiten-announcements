# Брендирование Справочного центра

Справочный центр теперь можно оформить в стиле вашей компании путем добавления логотипа, выбора основного цвета и настройки отображения названия портала. Изменения применяются не только к самому Справочному центру, но и к письмам, которые отправляются пользователям.

Функция доступна облачным клиентам Kaiten и в серверной поставке начиная с версии 58.52.5.

---

## Возможности оформления

В настройках появилась вкладка «Оформление» с функциями:

- загрузка горизонтального логотипа для шапки портала
- загрузка квадратного логотипа для писем и фавиконки
- выбор основного цвета интерфейса
- показ или скрытие названия портала рядом с логотипом

## Инструкция по настройке

1. Откройте пространство с привязанным Справочным центром
2. Нажмите значок шестеренки и выберите **Настроить** → вкладка **Оформление**
3. Загрузите логотипы:
   - Горизонтальный: PNG, 480×192 px, до 2 МБ
   - Квадратный: PNG, 256×256 px, до 2 МБ
4. Выберите основной цвет из палитры
5. Включите/выключите отображение названия портала
6. Сохраните изменения

Для возврата стандартного оформления нажмите «Сбросить настройки».
