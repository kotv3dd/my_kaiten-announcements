# Обновили управление External Webhooks

Теперь в аккаунтах с модулем «[Группы пользователей](https://faq-ru.kaiten.site/eb605b76-029d-44d9-94d1-6d4a6d20ef68)» к одному пространству можно подключать и редактировать сразу несколько webhook, а управлять ими в новом административном разделе [External Webhooks](https://faq-ru.kaiten.site/external-webhooks).

![Картинка 1](https://hq.kaiten.ru/api/documents/157f6aa6-91fd-4af1-84bb-ae1e444f230e/files/10e7bdf5-c139-4e28-b028-4bbdbf84566b)

*Функция уже доступна облачным клиентам Kaiten. В серверной поставке начиная с версии* *58.40.0*

> Обновление доступно только для аккаунтов с [модулем «Группы пользователей»](https://faq-ru.kaiten.site/eb605b76-029d-44d9-94d1-6d4a6d20ef68). Если модуль не подключен,  интерфейс останется прежним.

---

Раньше в настройках пространства можно было создать только один вебхук, включить его или выключить. Теперь вебхуков может быть несколько, каждый можно отредактировать, а для управления всеми интеграциями компании появился раздел в администрировании External Webhooks.

## Вебхуки в настройках пространства

Чтобы настроить вебхуки в определенном пространстве, откройте его настройки (иконка шестеренки рядом с пространством в левой панели), выберите **External Webhooks**.

Теперь здесь можно создать несколько вебхуков. Для этого нажмите кнопку «Создать».

> Доступ к разделу External Webhooks в настройках пространства по умолчанию есть у владельца аккаунта и пользователей с ролью администратора. Выдать доступ пользователям с другими ролями можно через [настраиваемые роли.](https://faq-ru.kaiten.site/nastraivaemye-roli-polzovateley)

![Картинка 2](https://hq.kaiten.ru/api/documents/157f6aa6-91fd-4af1-84bb-ae1e444f230e/files/3edfad42-7fc8-454a-bf8a-826151a7096d)

Введите название, ссылку и сохраните.

![Картинка 3](https://hq.kaiten.ru/api/documents/157f6aa6-91fd-4af1-84bb-ae1e444f230e/files/f3804925-9eff-416b-a58f-3a81e4945af0)

Чтобы изменить существующий webhook, нажмите на него. В раскрывшихся настройках его можно отредактировать, включить и выключить.

![Картинка 4](https://hq.kaiten.ru/api/documents/157f6aa6-91fd-4af1-84bb-ae1e444f230e/files/daaeee55-af07-4172-95e9-1a536b96ec9c)

> Если webhook используется сразу в нескольких пространствах, Kaiten покажет предупреждение перед изменением. Так вы поймете, что правка затронет не только текущее пространство.

## Раздел External webhooks в администрировании

В администрировании появился раздел **External Webhooks** — общий список вебхуков всех пространств компании. 

![Картинка 5](https://hq.kaiten.ru/api/documents/157f6aa6-91fd-4af1-84bb-ae1e444f230e/files/65a824d7-eb9b-46db-8f10-d552fe1c132e)

> По умолчанию административный раздел External Webhooks доступен владельцу аккаунта и пользователям с доступом к разделу «[Пользователи](https://faq-ru.kaiten.site/polzovateli-administrativnyy-razdel)». Чтобы получить доступ, обратитесь к одному из них.
>
> Подробнее о том, как выдать доступ, [читайте в статье →](https://faq-ru.kaiten.site/upravlenie-polzovatelyami-i-ih-pravami-dostupa)

В нем можно:

* создавать новые вебхуки;

* привязывать один вебхук сразу к нескольким пространствам;

  ![Картинка 6](https://hq.kaiten.ru/api/documents/157f6aa6-91fd-4af1-84bb-ae1e444f230e/files/3183948c-c09d-4513-8bdd-7dd1278546b8)


* видеть список всех вебхуков компании в виде таблицы: их названия, URL, пространства, к которым они привязаны, автора, статус активности;

* включать и отключать вебхуки;

* редактировать название, URL и список привязанных пространств;

* удалять вебхук;

  ![Картинка 7](https://hq.kaiten.ru/api/documents/157f6aa6-91fd-4af1-84bb-ae1e444f230e/files/5ba701bd-8def-4c67-83e5-a11e65df36dd)
