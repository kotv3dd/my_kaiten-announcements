# Kaiten Announcement Skill

Claude Code Skill для написания анонсов новых фич Кайтена.

## Установка

1. Открой терминал и запусти Claude Code:
   ```
   claude
   ```

2. Добавь источник скилла:
   ```
   /plugin marketplace add dlebedeva-kai/kaiten-announcements
   ```

3. Установи скилл:
   ```
   /plugin install kaiten-announcement
   ```

## Использование

В любом разговоре Claude Code напиши:
```
/kaiten-announcement
```

Скилл попросит прислать материалы о новой фиче и проведёт тебя по всем шагам.

## Что нужно подготовить

- Текстовое описание фичи
- Расшифровку встречи с разработчиком (если есть)
- Скриншоты интерфейса (поэтапные)

## Первый запуск

1. Напиши в Claude Code: `/kaiten-announcement`
2. Пришли скиллу:
   - Текст с описанием фичи
   - Скриншоты (прикрепи как файлы)
3. Дождись анализа — скилл изучит материалы и найдёт смежные статьи в базе знаний
4. Согласуй структуру анонса
5. Получи готовый анонс, внеси правки если нужно
6. Забери финальный Markdown
