# Редактор анонсов Кайтена

Агент для написания анонсов новых функций Кайтена. Проведёт по всем шагам: от сырых материалов до готового Markdown-текста.

## Первый запуск

1. Открой десктопное приложение Claude Code.
2. Начни новый диалог.
3. Напиши:
   > Установи локально для работы: github.com/dlebedeva-kai/kaiten-announcements
4. Claude Code скачает агента и подтвердит готовность.
5. Напиши «хочу написать анонс» — агент попросит прислать материалы и начнёт работу.

## Как работать с агентом

Агент попросит прислать:
- текстовое описание новой функции,
- расшифровку встречи с разработчиком (если есть),
- скриншоты интерфейса (прикрепи как файлы).

Затем предложит структуру, уточнит недостающее и напишет анонс. После показа можно давать правки в свободной форме.

Если хочешь, чтобы агент запомнил правило — добавь слово **«запомни»** к своей правке. Правило сохранится и будет применяться в следующих анонсах.

## Обновление агента

Если агент обновился, напиши в новом диалоге:
> Обнови локальную версию агента с github.com/dlebedeva-kai/kaiten-announcements
